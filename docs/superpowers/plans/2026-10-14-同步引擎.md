# 同步引擎（D 子项目）实施计划

> **交付状态**：✅ 已交付（D 子项目并入 main）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建成 `src/sync/` 同步引擎与 `sync` 六命令，把七鱼数据可重复、可中断续跑地同步进本地 DuckDB 库。

**Architecture:** 通用引擎（窗口切分→持久化限频闸门→拉取→配对核对→同事务「落库+推水位+清缺口」）+ 代码内任务声明（`src/sync/tasks/*.ts`，21 任务逐个声明窗口/水位/写策略/主键）。Store 接口为 D 扩展 `delete` 原语；schema 走 MIGRATIONS v2（数据表）/v3（sync_state 扩列）。

**Tech Stack:** TypeScript ESM（.js 后缀 import）+ vitest（`--maxWorkers=1` 红线）+ 既有 core（http.call/normalize/TokenBucket）与 store（Store 接口 + transaction 闭包）。

**Spec:** `docs/superpowers/specs/2026-10-14-同步引擎-design.md`（291 行 v1）——本计划从它论证，三条设计红线（spec §二）逐条有钉死用例。

## Global Constraints（全任务隐含遵守）

- **三条红线**（spec §二，违反即架构错误）：①主键只能是上游业务键，绝不含派生值/会随重跑变化的字段；本地派生列（`session_type` 等）必须确定性派生且不进主键 ②每窗口落库后行数配对核对，不符记 `sync_gaps`（reason=`count_mismatch`）③水位推进与数据落库**同一事务**（`store.transaction` 闭包）
- **测试红线**：`npx vitest run --maxWorkers=1 --no-file-parallelism <file>`；禁止 for/while 循环调 vitest；全仓 `npm test` 只许 Task 15 跑一次
- **分层**（layering.test.ts 既有规则 + D 新增）：`store/` 不 import `sync/`；`sync/` 不 import `commands/`；`core/` 不 import `store/`；auth/api 命令文件不得出现 `@duckdb` 字面量与 `/store/` import（零加载红线不波及）
- **双轨契约**（C1 裁定）：数据语句经 `store.upsert`/`store.delete`/`store.query`（公开接口）；BEGIN/COMMIT/ROLLBACK 一律经 `transaction` 闭包（禁止手写事务语句）；SQL 只允许代码内常量，新增字面调用点后更新 duckdb.ts 的调用点计数注释（当前 8 处）
- **Store 单实例串行**：所有 Store 方法调用串行 await，不并发（C1 契约）
- **TypeScript ESM**：相对 import 带 `.js`；运行时文本全中文；禁内部代号（D/D1 等里程碑编号不出现在 message/hint）
- **commit**：中文 message，末尾 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`
- **开源红线**：fixtures 全合成（标签A/#FF0000、1000001 等占位）；不出现本地路径/外部项目信息/真实企业数据
- **契约诚实性**：不硬编码会漂移的计数（知识库行数）；不支持的能力显式标注（实时快照 `unsupported: realtime`），不沉默缺席
- **错误契约**：复用 `usageFail`（退出码 2）/`fail`（1/3/4）双通道与 `thrownToExit` 扩展形态；hint 必须可执行

## Review Focus（最可能咬人的输入类，各配钉死用例归属）

1. **op 参数对静默全量**——`opEnd` 缺省/`=0`/只传一个时服务端不报错而返回全量 → Task 9 参数守卫用例
2. **省略 `startTime` 的考勤静默降级**——天粒度少抓 ~10 倍且不报错 → Task 8 任务声明测试断言请求体恒含 `startTime`
3. **假空**——同一请求先返回空再返回全量 → Task 5 引擎空窗口重试一次用例
4. **JSONL 尾行**——导出文件末尾非 JSON 标记行，不跳过即整批解析失败 → Task 11 解析用例
5. **纯 upsert 不删行**——坐席离职/无数据日陈旧行残留 → Task 3 `delete` 原语 + Task 8 deleteRangeInsert 用例（删旧插新后行数 == 新行数）
